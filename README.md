# Fuad Ashraf — Research and Engineering Portfolio

Selected engineering software, computational research, and original project materials. Source packages and documents are linked to their files; research-stage ideas are identified as such and are not represented as peer-reviewed or physically validated results.

## Featured projects

- [Engineering Question Generator](software/engineering-question-generator/README.md) — Python template-driven generation of structured engineering questions, solutions, and data exports. Includes the original source, a 100,000-question dataset, a verification-ready JSONL export, and a separate 1,062-question PDF/workbook.
- [EngiDraw Verified](software/engidraw-verified/README.md) — complete source snapshot of a browser-based engineering drawing application, with publication notes and validation boundaries.
- [EngineAI Studio](https://github.com/fuadashraf263-svg/engineai-studio) and [Axiomata Reference Compiler](https://github.com/fuadashraf263-svg/axiomata-reference-compiler) — larger software projects with source and technical documentation in their own repositories.
- [CRFCE C13-NX/R13-A audit](research/crfce-c13-nx-r13a/) — source-only electrical-engineering screen, trial CAD audit, figures, and technical annex. The conclusion is limited to the sampled surrogate; physical-machine performance is not proven.
- [SERT / URTM bounded verification](software/sert-urtm-bounded-verification/) — original reference code and a bounded numerical patch test; this does not establish empirical fracture validation.
- [Shaft Witness source sample](software/shaft-witness-source/) — original prototype and replay tools. Restricted third-party bearing data and derived results are excluded; see its README for the data-license boundary.
- [VectorOne XR source artifact release](research/vectorone-xr-source-release/) — 50 original CAD, Python, Lean, JSON, design-basis, and figure files with SHA-256 hashes and explicit concept-stage validation limits.
