# Data provenance and sharing boundary

The full replay plan identifies the Paderborn KAt Bearing DataCenter as the source of the waveforms. The data center's current data page states that the dataset is licensed under Creative Commons Attribution-NonCommercial 4.0 International, permits noncommercial academic use with citation, and asks users to contact the author for commercial use.

This public portfolio snapshot includes only Fuad-authored source code and planning documents. It excludes the raw MAT recordings, the 1,200-row replay output, the parent analysis CSV, and the output report that contains data-derived scores. The code references those external inputs and therefore is not a complete replay package by itself.

No claim of physical validation or machine diagnosis is made by this source-only publication.
